# 微信视频电话实时中文字幕（个人 Windows 版）

## 功能
- 抓取 Windows 当前默认扬声器/耳机的系统声音（WASAPI Loopback）
- 用 FunASR `paraformer-zh-streaming` 做中文流式识别
- 字幕透明悬浮、始终置顶
- 不保存原始录音
- 不注入、不修改微信

## 适用
Windows 10/11，推荐 Windows 11 x64。
建议 Python 3.11 x64。

## 第一次安装
1. 安装 Python 3.11 x64：
   https://www.python.org/downloads/windows/
2. Python 安装界面务必勾选 `Add python.exe to PATH`。
3. 解压整个文件夹到例如：
   `D:\WeChatLiveCaption`
4. 双击 `install.bat`。
5. 安装成功后关闭窗口。

## 每次使用
1. 先接好你实际使用的耳机/扬声器。
2. 打开微信电脑版并开始视频/语音电话。
3. 双击 `start.bat`。
4. 第一次启动会自动下载 Paraformer 中文模型，需要联网。
5. 看到“正在监听：xxx”后，对方讲话即可出现中文字幕。
6. 鼠标左键拖动字幕框可调整位置。
7. `Ctrl + ↑` 放大字幕；`Ctrl + ↓` 缩小字幕；`Esc` 退出。

## 重要限制
当前个人版抓的是“默认播放设备”的所有声音，不只微信。
因此微信通话时不要同时播放网页视频、音乐等，否则它们也可能进入识别。

它默认只抓电脑播放出来的声音，所以主要显示“对方”的字幕。
你自己的麦克风声音通常不会进入这一路 Loopback。

## 耳机切换
程序启动时会锁定当时的默认播放设备。
如果你从扬声器切换到蓝牙耳机，请退出后重新双击 `start.bat`。

## 没字幕时
先确认：
- 微信声音确实能从当前耳机/扬声器听到；
- Windows 音量混合器里微信没有静音；
- 不要在程序启动后切换播放设备。

可在命令行运行：
`.venv\Scripts\python.exe -m pyaudiowpatch`
查看系统识别到的 WASAPI / Loopback 设备。

## 模型与网络
FunASR 的 `paraformer-zh-streaming` 是中英文流式 ASR 模型。
第一次启动需要下载模型；下载完成后，后续识别可以在本机完成。

## 隐私
本脚本不主动保存 WAV/PCM 音频文件，也没有把识别结果上传到自建服务器的逻辑。
但首次下载模型需要联网；第三方依赖仍受各自软件/模型许可协议约束。

## 性能
本版本默认 `device="cpu"`，方便普通个人电脑使用。
如果 CPU 较老，首次加载及实时识别可能较慢。
